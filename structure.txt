📌 Features
- Add, view, search, and update menu items
- Manage food categories and prices
- Register customers
- Create orders with multiple items
- Automatically calculate totals and GST
- Update order status
- Record payments
- View order history
- Generate daily sales reports
- Identify popular menu items
- Store data in JSON files

🛠️ Tech Stack
- Python
- JSON
- Datetime
- UUID
- OS
