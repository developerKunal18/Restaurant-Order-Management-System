# Restaurant Order Management System

A Python command-line application for managing restaurant menus,
customers, food orders, payments, and sales reports.

## Features

- Menu management
- Customer registration
- Multiple items per order
- Automatic subtotal and GST calculation
- Order status management
- Payment recording
- Receipt ID generation
- Order search
- Daily sales reports
- Popular item reports
- Pending payment reports
- JSON data persistence

## Technologies

- Python
- JSON
- Datetime
- UUID

## Installation

Clone your repository:

```bash
git clone https://github.com/yourusername/restaurant-order-management.git
```

Navigate into the folder:

```bash
cd restaurant-order-management
```

Run the project:

```bash
python main.py
```

No external packages are required.

## Workflow

1. Add menu items.
2. Register customers.
3. Create an order.
4. Update the order status.
5. Record the payment.
6. View sales and popular-item reports.

## GST

The sample program uses a configurable 5% GST rate for demonstration.
Verify the applicable GST rate and tax treatment before using it for
real restaurant billing.
